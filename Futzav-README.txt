# Futzav Portfolio

This repository is the GitHub starting point for the Futzav portfolio.

## Live portfolio

[Visit the portfolio](https://futzavng.lovable.app/)

## Important: this ZIP is not the website source code

A website URL points to the published site; it does not contain the editable project files needed to build, run, or maintain the site from GitHub. This starter ZIP contains this README only. It does not include the Lovable source code.

To make a real GitHub code repository, connect or export the project from the Lovable account that owns it:

1. Sign in to Lovable and open the Futzav portfolio project.
2. Open **Project settings → Git** and choose the GitHub connection option. Follow the prompts to authorize the right GitHub account and connect the project to a repository. Lovable's GitHub integration can create and sync the project repository.
3. If you only need a code copy, use **Download codebase** in **Project settings → Git** (or in the code editor, if available), then put the downloaded project files in your GitHub repository.
4. Check that the source files and any setup instructions are present in GitHub. Keep credentials and secret keys out of the repository.

Lovable's menu labels and available options can change. For the current walkthrough, see [Lovable's GitHub sync documentation](https://docs.lovable.dev/integrations/github).
